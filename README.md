## 📖 About the Project

**WarmPaws** is a cat-focused web project designed to provide a welcoming online experience for cat lovers. The project uses modern frontend technologies to build a responsive interface and explore interactive web development features.

This project helped me practice React component development, client-side routing, styling, and integrating frontend applications with Firebase.

## ✨ Features

- 🐱 Cat-focused user interface
- 📱 Responsive layout for different screen sizes
- 🧭 Client-side navigation with React Router
- 🔥 Firebase integration
- 🎨 Modern styling with Tailwind CSS and DaisyUI
- 🔔 User notifications and interactive UI components
- ✨ Animations and visual enhancements

*Note: The feature list should reflect the functionality currently implemented in the application.*

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Mahidi-Hasan-Supon/WarmPaws-Cat.git
```

**2. Navigate to the project directory**

```bash
cd WarmPaws-Cat
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Open the URL displayed in your terminal, usually `http://localhost:5173`.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Build the application |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
